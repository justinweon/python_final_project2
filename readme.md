# 📚 도서 관리 시스템 (Library Management System)

파이썬 OOP 구조로 작성된 CLI 기반 도서 관리 프로그램입니다. 종이책과 전자책을 구분하여 관리하며, 대여·반납 및 검색 기능을 제공합니다.

---

## 💡 주요 기능

* **📖 도서 등록**: 종이책(페이지 수)과 전자책(파일 크기)을 구분하여 등록
* **🔍 도서 검색**: 제목 또는 저자 키워드 검색 (대소문자 미구분)
* **🔄 대여 및 반납**: ISBN 기반의 실시간 대여 상태 관리
* **📋 목록 조회**: 전체 도서 정보 및 대여 가능 여부 확인

---

## 📁 프로젝트 구조

* `main.py` - CLI 메뉴 및 사용자 입출력 처리
* `library.py` - 도서 검색, 대여, 반납 등 핵심 비즈니스 로직
* `book.py` - 도서 기본 클래스 (캡슐화 및 대여 상태 관리)
* `specialized_books.py` - `Book`을 상속받은 `Paperbook`, `Ebook` 클래스
